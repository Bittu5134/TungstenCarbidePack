# Tungsten Carbide Pack (Minecraft Java Edition)

A Minecraft resource pack applying scientifically plausible metallurgy to Netherite, inspired by real-world materials science and the **"Jeweller reviews Minecraft netherite"** theory.

---

## 🔬 The Metallurgical Theory

In real-world engineering and jewelry fabrication, **Tungsten Carbide (WC)** is an ultra-hard, wear-resistant cermet (ceramic-metallic composite). The in-game Netherite workflow matches this process:

| Minecraft Element | Real-World Metallurgical Counterpart | Scientific Explanation |
| :--- | :--- | :--- |
| **Ancient Debris** | **Wolframite Debris** | Refractory tungsten source ($T_m \approx 3{,}422^\circ\text{C}$), extremely heat resistant. |
| **Netherite Scrap** | **Refined Tungsten Scrap** | Purified tungsten metal recovered after smelting. |
| **Gold Ingot** | **Ductile Metallic Binder** | Soft, highly ductile metal that prevents brittle fracture in carbide cermets. |
| **Netherite Ingot** | **Tungsten-Gold Ingot** | Sintered composite precursor alloy of tungsten and gold binder matrix. |
| **Diamond Gear** | **Carbon Substrate ($\text{C}$)** | Diamond is pure elemental carbon. |
| **Smithing Upgrade** | **Carbide Sintering Upgrade** | Tungsten reacts with the diamond's carbon to synthesize **Tungsten Carbide ($\text{WC}$)** bonded in a gold matrix. |
| **Netherite Armor / Tools** | **Tungsten Carbide Equipment** | Sintered Tungsten Carbide-Gold composite gear. |

## 🛠️ Installation

1. Copy the `resourcepacks/TungstenCarbidePack` folder (or compress it into a `.zip`) into your Minecraft `.minecraft/resourcepacks/` directory.
2. Open Minecraft -> **Options** -> **Resource Packs...**.
3. Move **Tungsten Carbide Pack** to the active column and click **Done**.
